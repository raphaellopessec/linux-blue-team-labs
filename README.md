# linux-active-intrusion-investigation
Investigação de Invasor Ativo e Reverse Shell em Linux

Conteúdo estudado
- análise de logs SSH
- brute force
- escalada de privilégio
- reverse shell
- investigação de conexões
- análise de processos
- pstree
- netcat

Ferramentas utilizadas (bash)
- journalctl
- ss
- ps
- pstree
- lsof
- nc

Conceitos
- diferença entre SSH e reverse shell
- LISTEN vs ESTAB
- relação entre processos
- investigação de invasor ativo
- processo legítimo vs uso malicioso
